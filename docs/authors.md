## Authors

- **Aurélien Nicosia**. Author, maintainer.\
  Adapted the research functions for the package and added
  visualisations, result summaries and configurable state taxonomies

- **Ilhem Bouderbala**. Author.\
  Original research functions and published methodological framework

- **Daniel Fortin**. Contributor.\
  Published methodological framework
